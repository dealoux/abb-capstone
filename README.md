## Run the app

Follow these steps to set up the environment and launch the Streamlit app.

### Prerequisites

- Python 3.12 (project requires Python >=3.12,<3.13)
- Poetry installed ([installation guide](https://python-poetry.org/docs/#installation))

### Install dependencies

Run these from the project root (the folder containing `pyproject.toml`).

```fish
poetry install
```

### Run

Start the Streamlit app:

```fish
poetry run python ./run.py
```

Then open your browser to:

- <http://localhost:8501>

If that port is already in use, Streamlit will prompt to use another port.
